## 📂 各章節核心技術突破與反思

### 📌 作業 01 — 個人網站與相簿：靜態網頁的結構思維
* **專案概述**：設計高質感的個人名片頁面，引入玻璃擬態（Glassmorphism）與漸層背景。
* **技術精髓**：核心在於理解「資訊架構」。`gallery.html` 實作了以 URL query string (`?category=sports`) 驅動內容的模式，這背後的概念正是現代前端路由的雛型。學習如何用 HTML 標籤的層級去對應內容的層級，並用 CSS 賦予網頁視覺情緒。

### 📌 作業 02 — 生活習慣問卷：表單的本質是資料的通道
* **專案概述**：具備完整驗證機制的綜合性用戶調查問卷。
* **技術精髓**：理解表單的每一次提交都是一條資料的產生命令。單選按鈕代表排他性選擇，複選框代表並列性愛好。前端表單不是單純的 UI 元件集合，而是使用者意圖轉換為結構化資料的第一道關卡。

### 📌 作業 03 — Node.js Web Server：從終端機到瀏覽器
* **專案概述**：使用 Node.js 內建 http 模組，在本地端監聽 3000 埠號，渲染帶有樣式的歡迎畫面。
* **技術精髓**：JavaScript 不再只是印出文字的腳本，而是能夠處理 HTTP 請求、操作回應物件、與瀏覽器進行雙向溝通的伺服器端語言，由此切入全端開發最核心的「請求—回應（Request-Response）」循環。

### 📌 作業 04 — JavaScript 十題練習：語言特性與程式思維的交叉訓練
* **專案概述**：涵蓋條件判斷、迴圈、陣列 `reduce()`、物件屬性存取與 JSON 操作的 10 道演算法練習。
* **技術精髓**：建立「將問題拆解為程式邏輯」的直覺。例如透過購物車模擬，練習狀態管理的最小模型：商品的新增、刪除、數量變更與折扣計算。

### 📌 作業 05 — 部落格系統：全端應用的最小可行模型
* **專案概述**：採用 MVC 架構，利用 Express + SQLite + EJS 打造類似 Threads 風格的社群平台。
* **技術精髓**：
  * **路由設計**：體現 URL 參數化與 RESTful 設計哲學。
  * **模板引擎 (EJS)**：在伺服器端將資料動態嵌入 HTML。
  * **安全認證**：結合 `bcrypt` 密碼雜湊與 `express-session`，展示如何在不信任的網路環境中透過簽名建立信任。

### 📌 作業 06 — JS 函式學習中心：JavaScript 中最被低估的力量
* **專案概述**：打造 Quiz 測試與 Study 學習雙模式系統，聚焦 JavaScript 核心設計哲學。
* **技術精髓**：深入理解**閉包 (Closure)** 讓函式記住其詞法作用域的強大特性（私有變數、工廠函式）；掌握 **IIFE** 隔離變數宇宙的技巧；運用 `map`、`filter`、`reduce` 等**高階函式**讓資料處理宣告式化。

### 📌 作業 07 — 後端模式 JS 挑戰：從前端思維到後端思維的轉換
* **專案概述**：為後端開發量身打造的補強練習，包含解構賦值、Error-First Callback、非同步流程控制。
* **技術精髓**：強迫自己「先處理錯誤，再處理資料」，實踐防禦性編程（Defensive Programming）。利用 `setTimeout` 模擬非同步 DB 查詢，隔離理解回呼函式的流程控制。

## 👑 重點核心項目：期中專案 — NEXT-TETRIS UNIVERSE 全端網頁俄羅斯方塊

> **技術亮點**：擺脫陽春的傳統腳本與單機限制，在不使用 Python 的情況下，利用現代全端 **JavaScript/TypeScript 生態圈 (Next.js App Router)** 實現高頻遊戲引擎、即時實時渲染、後端 API 會員系統與檔案持久化。

### 核心功能模組
1. **🔒 完整會員身分系統**：處理 `/api/auth` 註冊與登入驗證。登入後前端透過 `localStorage` 保持工作階段，後端自動進行重複帳號審查。
2. **🏆 雲端同步公開排行榜**：玩家結束遊戲後自動上傳分數至 `/api/leaderboard`。採取**「一人一卡、只保留最高分」**機制防止惡意洗板，並在前端給予目前登入玩家青色高亮標記。
3. **🚀 智慧型影子方塊 (Ghost Piece)**：在棋盤最底部實時渲染半透明虛線落點影子，顏色自動跟隨當前操作方塊的主色，大幅提升高速盲打精準度。
4. **💥 街機風消行 Combo 特效**：連續落地消行可累積 Combo 乘數並給予分數加成，畫面上方會跳出向上飄移的動態特效字（如 `👑 TETRIS! 👑`），並觸發短暫的黃金霓虹邊框閃爍。
5. **🎨 多主題背景即時切換**：內建主題切換器，提供「賽博暗黑、霓虹深紫、駭客任務、星際深藍」四款風格，面板外框與流光裝飾條皆可一鍵無縫切換。

### 核心技術突破與優化反思（本人獨立主導）

* **觸頂判定（Game Over）邏輯漏洞修復**
  * *問題根源*：早期版本僅以固定後方塊 Y 軸小於 0 為條件，導致方塊在頂端（Y=0）出生點卡死疊滿時，遊戲不會結束而直接畫面卡死。
  * *優化方案*：我重新設計了雙重防護機制：1. 當新方塊甫生成於頂端起點即發生碰撞；2. 消行結算後，第 0 行仍有任何殘留的實體方塊細胞（`filteredGrid[0].some(cell => cell.filled)`）。滿足任一條件立即宣告 Game Over，完美修復漏洞。
* **資料庫檔案持久化（File Persistence）**
  * *問題根源*：最初將用戶與排行陣列存在全域變數中，導致 Next.js 在開發期間一觸發「熱重載 (Hot Reload)」或伺服器重啟，所有歷史資料便會蒸發。
  * *優化方案*：在不引入繁重外部資料庫的前提下，我改用 Node.js 內建的 `fs` (File System) 模組建立 `db.json` 作為實體資料庫中繼站，利用 `fs.readFileSync` 與 `fs.writeFileSync` 機制，讓任何註冊與高分覆蓋都能立刻同步寫入硬碟，無畏伺服器重啟。
* **連續消行動畫字體卡死與 DOM 刷新優化**
  * *問題根源*：在 React 中短時間內連續觸發相似的 Combo 特效時，React 的虛擬 DOM (Virtual DOM) 會判定節點不需重新掛載（Remount），導致 CSS keyframes 飄移缺陷動畫只播了一次就卡住。
  * *優化方案*：我在特效狀態中引入了 `Date.now()` 時間戳記作為 HTML 特效元素的唯一 `key` 值（`key={effect.id}`）。利用 React 的 Key 變更機制，強迫 React 在每一次消行時將組件視為全新品進行重新銷毀與掛載，成功確保每一次 Combo 街機動畫都能 100% 完美重播，大幅提升打擊爽快感。
* **智慧影子方塊（Ghost Piece）雙層無衝突渲染**
  * *問題根源*：底部半透明提示方塊必須隨玩家左右移動或旋轉時即時更新，且不能與當前下落的實體方塊產生顏色衝突或閃爍。
  * *優化方案*：在 `renderDisplayGrid` 函數中設計了「雙層模擬混合演算法」。先複製一份當前固定的棋盤背景，透過 `while` 迴圈不斷向下測試 `checkCollision` 直到撞擊，計算出落點 `ghostY` 並鋪上標記為 `isGhost: true` 的虛線細胞，接著在相同網格上疊加真實控制中的方塊。當兩者重疊時，以實體方塊樣式覆蓋影子，實現完全流暢、無延遲且色彩連動的影子投影。
